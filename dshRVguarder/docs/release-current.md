# RVguarder v0.2.1-rc.1

本版本整合上游安全能力与 DSH 内嵌界面、托管运行环境，提供 **Windows x64 / DSH 0.2.1-rc.3** 预发布整包。安装后由插件自动管理后台，无需另装 Python 或手动启动服务。

## 更新内容

- DSH 插件页与“设置 → RVguarder”集成概览、调用与审批、规则与 RV、扫描报告和审计；支持中英文、亮暗主题与键盘导航。
- 后台随插件启停，运行文件按内容哈希缓存；从任意目录启动 DSH，保留会话工作目录和同一 profile 的实例身份。
- 可选择宿主子代理语义模式，复用 DSH 当前模型路由；不可用时回退本地分析，语义输出不授予权限。
- 增加有界任务授权及任务内命令类别审批复用；仍检查主体、会话、工作区、有效期和风险约束。
- 改进工具参数和多资源角色建模、委派链记录、决策原因归因，并区分预期、潜在和已观察效果。
- 执行结果未知时保留未确认状态；只有确认成功的完成事件提交成功历史。并发握手与持久化连接复用减少重复开销。

## 安装

参见 [下载安装](deployment.md)。发布附件中的 `.tgz` 是完整插件；`-distribution.zip` 用于建立独立发行仓库，根目录包含 `package.json` 和运行时。GitHub 自动生成的源码压缩包不能替代整包。

版本约定：产品、npm 插件为 `0.2.1-rc.1`；Python 发行元数据为等价的 `0.2.1rc.1`。DSH SDK 兼容声明仍为 `0.2.1-rc.2 / rc.3`，PMKB 仍为 `1.2.0`。

## 验证与范围

本次发布的构建与测试结果见上游的 [发布验证记录](https://github.com/HorizonExploration/RVguarder/blob/master/docs/dev/release-v0.2.1-rc.1.md)。历史候选的测试与截图保留为历史证据，不替代本包验收。

Windows x64 是本次整包目标。rc.2 核心兼容保留；rc.2 内嵌 UI、Linux/arm64 整包、在线模型、真实 PTC 沙箱及长期稳定性没有在本次发布中完成验收。插件覆盖宿主工具调用路径，不是系统级沙箱；同一用户完整权限下的任意进程隔离不在承诺范围内。遇到恢复锁定或未知执行结果时，应先核实执行结果，避免重复操作。
