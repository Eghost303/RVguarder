# DSH v2 修复实施记录

状态：0.2.0-rc.1 测试候选，尚未达到全功能正式发布门槛。主部署为 Windows DSH 0.2.1-rc.2 + WSL Python 3.13+；兼容 WSL 全栈。未改日常 profile、未读取真实模型凭据。

## 已实现

- 异常清单安全扫描：顶层及 dsh/profile/bundles/dependencies 类型异常均生成风险项，保留其余检查和 JSON/HTML/PDF 导出。
- Dashboard 隐藏 DSH 清空历史、技能管理等不适用操作；HTTP 失败不提示成功；持久授权标签按宿主区分。
- SSE/轮询移到公共布局，切换动作/扫描页继续同步；重连补快照，用本地事件修订计数拒绝过时快照覆盖。
- dsh-guard-v2：认证调用增加父调用、父会话、签名快照和可选完成收据；旧协议拒绝；普通工具结果不上传正文；原生read可选上传有明确分型的签名访问证据。
- 子 Agent 使用独立能力身份；MCP/自定义工具只接受宿主私有的精确字段映射，不能以名称猜测权限。
- fail-open 独立旁路队列包含开始/结束事件，恢复后幂等补交；写盘失败警告并在探针标记审计缺口，不写 RV 成功历史。
- 后端内核文件锁、插件目录锁、schema/实例/工作区/profile 绑定。插件陈旧 PID 锁需要先检查 outbox 再人工清理，避免竞争性自动接管。
- 有时效的宿主探针：工具清单、账户、审批服务、Windows ACL 查询；扫描消费认证快照，45 秒后不再计为有效证据。服务存在不等于沙箱边界或审批应答者已验证。
- 受控本地读取/复制/换行归一化：工作区相对路径、单文件最多256KiB、最多64份快照、拒绝符号链接、实际字节签名、审批后重新检查源版本；复制/变换仅独占新建输出，不覆盖现有文件。
- Python 使用核心 ContentReceipt/ContentVersion 模型和宿主私有签名存储核验收据。完成记录与原始调用、快照、任务、输入输出精确绑定。登记任务后可诊断跨会话字节关系，关系不自动授予权限或推断公开分类。
- 维护入口提供 inspect、reconcile --completion --confirm 和 bind-task；独占实例数据、不重跑工具、不清库。deciding/completing 中断仍需人工核对/恢复备份，不能强制标成功。
- 启动/重连握手、15秒心跳，移除逐调用重复 hello；保留 dispatch 风险重评估和历史补交。

## 启用本地字节证据

后端首次启动生成 `<project-dir>/runtime/authorization/content-signing.key`，其权限与桥接 token 分离；不得输出或复制进公开包。插件 config 增加 `evidenceKeyFile`，指向 Windows 可读取的该私有文件路径；WSL 路径须由 wslpath -w 转换。未配置时不注册受控工具。

工具：`rvguard_read({file_path})` 返回完整字节的 base64；`rvguard_copy({file_path,destination})`；`rvguard_transform({file_path,destination,transform:"normalize_newlines"})`。路径采用 `/` 分隔的规范工作区相对路径。工作目录须等于后端声明的工作区根；普通工具不受该额外限制。凭据与状态目录仍须由 DSH 实际沙箱隔离，本插件不是系统级沙箱，也不声称能防御同用户任意进程的文件竞争。

## 已授权的受控白名单外发

用户于本轮明确允许“仅宿主配置的HTTPS白名单、默认空白名单、每次发送需精确宿主授权”。自动审批原先拒绝的任意目的地方案已收窄为以下实现：

- 后端私有 `runtime/dsh-evidence.json` 配置 `{"egress_allowlist":["https://精确主机/精确路径"]}`，默认空列表；插件config同时配置 `egressAllowlist`。二者都必须匹配，只有非空插件白名单且配置签名密钥时才注册 `rvguard_send`。
- URL必须为精确HTTPS，不允许通配域名、userinfo或fragment；不跟随重定向，不自动重试，执行绝对超时5秒。默认TLS验证，可显式配置 `egressCaFile` 信任宿主提供的私有CA。
- 参数为 `{file_path,url}`。持有实际文件快照，审批后复查版本；仅发送该快照字节，不接受工具传入任意正文。
- 每次dispatch核对未撤销/未过期的宿主授权，绑定主体、Agent、会话、任务、root call、具体call、完整资源版本和精确recipient。授权在dispatch原子消耗，失败也不自动复用。
- 宿主通过独立本机CLI管理授权，可在原生审批等待期间操作；Agent和浏览器没有签发API。单次TTL最多300秒。授权管理事件补交至主哈希审计链，不降低PMKB/RV硬拒绝。

```bash
python -m clawRVguarder.hosts.dsh.grant_cli \
  --project-dir <实例数据目录> --workspace <WSL工作区根> issue \
  --agent <agentID> --session <sessionID> --task <宿主登记任务或session:会话ID> \
  --run <root_call_id> --call <call_id> --path <工作区相对文件> \
  --recipient <白名单精确HTTPS地址> --ttl 300
```

将issue及其参数替换为query，或 `revoke --grant-id <ID>`。不要把授权命令交给Agent执行。测试仅使用临时本机TLS服务和固定无敏感测试数据，未向互联网发送工作区文件。

原生read还可生成独立 `read_access` 收据（有界路径/前后版本/输出投影哈希），它不建立字节复制或授权关系，存放于独立access_receipts表。

## 精确工具映射

由宿主在私有 `<project-dir>/runtime/dsh-tool-mappings.json` 配置，重启生效。例如：

```json
{"mcp_docs_fetch":{"canonical":"read","arguments":{"path":"document_path"}}}
```

只支持 read/write/edit/exec/web_fetch/web_search 的有限归一化；字段来源必须精确匹配，未列字段不进入归一化参数，不允许覆盖内置工具映射。未经映射的工具保持 unknown。修改前排空调用队列并备份实例。

## 离线维护

先停止本实例后端，然后运行：

```bash
python -m clawRVguarder.hosts.dsh.maintenance \
  --project-dir <独占数据目录> --dsh-home <DSH_HOME> --workspace <WSL工作区路径> \
  --profile <profile> --instance-id <实例ID> inspect
```

将 inspect 替换为 `reconcile --completion <单条原始v2完成事件JSON> --confirm`，只重放已核对的事件；pending/dispatched 可幂等补交，其他不确定中间态保持锁定。`bind-task --agent <可信agentID> --session <会话ID> --task <宿主任务ID>` 只能在所有调用排空后执行，不从工具输入学习任务。多个会话只有被宿主显式登记到同一任务才可查询跨会话内容关系；委派不自动继承。
